# CoopControl Web

Sistema de gestión integral para cooperativas, desarrollado con **Blazor Web** y **.NET 9**.

![.NET](https://img.shields.io/badge/.NET-9.0-512BD4?style=flat&logo=dotnet)
![Blazor](https://img.shields.io/badge/Blazor-Web-512BD4?style=flat&logo=blazor)
![Radzen](https://img.shields.io/badge/Radzen-UI-FF6B6B?style=flat&logo=radzen)
![License](https://img.shields.io/badge/License-MIT-green?style=flat)

##  Características

-  **UI Moderna** - Componentes Radzen Blazor
-  **Modo Oscuro/Claro** - Toggle de apariencia
-  **Responsive** - Adaptable a móviles y tablets
-  **Dashboard** - Estadísticas en tiempo real
-  **Gestión de Socios** - CRUD completo
-  **Cooperativas** - Administración múltiple
-  **Reportes** - Generación de informes
-  **Configuración** - Personalización del sistema

##  Tecnologías

| Tecnología | Versión |
|------------|---------|  
| .NET | 9.0 |
| Blazor | Web (Interactive Server) |
| UI Framework | Radzen.Blazor |
| CSS | Custom + Material Icons |


## Instalación

```bash
# Clonar repositorio
git clone https://github.com/tu-usuario/CoopControlWeb.git

# Navegar al directorio
cd CoopControlWeb

# Restaurar dependencias
dotnet restore

# Ejecutar
dotnet run
